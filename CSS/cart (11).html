KEMET CSS - تقسيم الملفات 1) اعمل فولدر داخل المشروع اسمه: css 2) انسخ الملفات الثمانية الموجودة داخل مجلد css/ إلى هذا الفولدر: 01-base.css 02-header.css 03-home.css 04-shop.css 05-auth.css 06-cart-ai.css 07-footer.css 08-responsive.css 3) استبدل style.css القديم بملف style.css الموجود هنا. 4) مهم: لا تغيّر أي HTML. كل صفحات HTML تظل تستخدم: 5) ترتيب الملفات مهم، لذلك لا تغيّر ترتيب @import داخل style.css. 6) بعد النقل، شكل المشروع يكون تقريباً: KEMET/ ├── index.html ├── products.html ├── login.html ├── register.html ├── cart.html ├── style.css ├── css/ │ ├── 01-base.css │ ├── 02-header.css │ ├── 03-home.css │ ├── 04-shop.css │ ├── 05-auth.css │ ├── 06-cart-ai.css │ ├── 07-footer.css │ └── 08-responsive.css └── ... ملاحظة: التقسيم لم يغيّر قواعد الـ CSS نفسها؛ تم فقط نقل الأقسام إلى ملفات منظمة.
